# CLAUDE.md

> `CLAUDE.md` and `AGENTS.md` are autogenerated by `/Init`. Do not edit directly -- run `/Update` to regenerate.

Media processing and acquisition for the forge ecosystem: image format conversion, raster-to-vector tracing, video-to-GIF, audio/video transcoding, and downloading media with yt-dlp.

## Skills

| Skill | What it does |
|-------|-------------|
| **MediaCapture** | Download video/audio/subtitles from YouTube + ~1800 sites via yt-dlp |
| **RasterToVector** | Multi-color bitmap-to-SVG conversion via ImageMagick + potrace |

Planned: image format conversion (HEIC/PNG/WebP/JPEG), video-to-GIF, and A/V transcoding and trimming.

## Install / Verify

```bash
make install          # deploy skills (Claude, Gemini, Codex, OpenCode)
make verify           # check skills deployed across all providers
make clean            # remove previously installed skills
make test             # validate-module convention checks
```

### Dependencies

```bash
brew install imagemagick potrace ffmpeg yt-dlp
```

ffmpeg and yt-dlp are also declared in forge-provision's Brewfile; this module
holds the skills that drive them, not the install.

## Architecture

```
skills/
```
